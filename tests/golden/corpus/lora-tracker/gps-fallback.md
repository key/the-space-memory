# 山間部での GPS 測位フォールバック

深い谷や樹冠の下では GPS の衛星捕捉に時間がかかり、測位が失敗する
ことがある。動物の行動範囲を継続的に把握するには、GPS が失敗した際に
LoRa ゲートウェイの受信強度から大まかな位置を推定するフォールバックが
有効だった。

複数のゲートウェイで同じ送信を受信できた場合は受信強度の差から簡易的な
三点測位も試したが、山間部では反射波の影響で誤差が大きく、実用には
GPS の再試行間隔を短くする方が効果的だった。
