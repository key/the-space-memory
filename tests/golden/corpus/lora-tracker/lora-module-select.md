# LoRa モジュール選定メモ

動物の首輪に取り付ける追跡タグには Semtech の SX1262 を採用したチップが
省電力性能で優れている。従来の SX1276 系と比べて受信電流が半分程度に
抑えられており、電池駆動での長期運用に向く。

山間部での運用を想定する場合、見通し距離が確保しにくいため送信出力の
上限に加えてスプレッディングファクタの調整が到達距離に効いてくる。
SF を上げるほど到達距離は伸びるが送信時間が長くなり電池消費も増える
トレードオフがある。
