# SQLite FTS5 による全文検索インデックス

SQLite の FTS5 拡張は仮想テーブルとして全文検索インデックスを提供する。
外部の検索サーバーを立てずに、単一のデータベースファイルの中で転置
インデックスと通常のテーブルを同居させられるのが大きな利点である。

トークナイザーには unicode61 を指定しつつ、日本語の分かち書き結果を
事前にスペース区切りで渡すことで lindera のセグメンター出力をそのまま
インデックスできる。スキーマやトークナイザーを変更した場合は既存の
インデックスとの整合性が崩れるため、DB 全体の再構築が必要になる。

rusqlite のバンドル機能を使うことで、システムにインストールされた
SQLite バージョンに依存せずビルドできる。
