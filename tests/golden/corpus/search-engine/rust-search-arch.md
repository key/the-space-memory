# Rust 製ハイブリッド検索エンジンの構成

検索デーモンを Rust で実装する場合、全文検索（FTS5）とベクトル検索を
別々のリトリーバーとして走らせ、RRF（Reciprocal Rank Fusion）でスコアを
統合する構成がよく使われる。各リトリーバーはそれぞれ独立に候補集合を
返し、順位の逆数を足し合わせることで単一のスコアに融合する。

推論処理はレイテンシが大きいため、常駐する子プロセスとして分離し
UNIX ソケット経由でリクエストを受け付けるのが定石である。デーモン本体は
DB の唯一の書き込み担当とし、読み取り用のコネクションプールを別に持たせる
ことで、検索リクエストと書き込みリクエストの詰まりを防げる。
