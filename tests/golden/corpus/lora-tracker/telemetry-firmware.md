# 位置トラッカーのファームウェア設計

首輪型トラッカーのファームウェアは GPS 測位とLoRa送信の2つのタスクを
低電力タイマーで交互に起動する構成にした。常時 GPS を起動すると電池が
数日で尽きるため、移動を検知したときだけ測位間隔を短くする適応型の
スケジューリングを組み込んでいる。

テレメトリーのペイロードには緯度経度に加えてバッテリー残量と直近の
移動距離を含め、受信側のゲートウェイでバッテリー切れの予兆を検知
できるようにしている。
